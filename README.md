# astrbot_plugin_mood · 心情引擎（dsh-mood 的 AstrBot 移植版）

> 这是**模拟情绪**，不是模型的真实感受。它不读取模型内部状态，也不代表任何主观体验；
> 所有记录都带 `simulated: true`。它只影响**说话语气**，不影响事实、安全判断与权限。

原版是 DSH 桌面端的 Cordis 插件 `dsh-mood`（`src/index.js` 2003 行 / `client.js` 146KB）。
本移植按源码逐段重写为 AstrBot（Python）插件，**不精简功能**，只替换host 层接口。

插件 id：`astrbot_plugin_mood` ｜ 版本 1.0.0 ｜ 要求 AstrBot >= 4.0.0 ｜ 默认 `enabled: false`（装上也先不生效）

## 一、六维心情状态机

| 维度 | 中文 | 含义 | 范围 | 基线 | 半衰期 |
|---|---|---|---|---|---|
| valence | 心情 | 整体愉快程度 | 0–100 | 55 | 6 小时 |
| arousal | 劲儿 | 活跃/紧张程度 | 0–100 | 55 | 6 小时 |
| dominance | 底气 | 事在手里的感觉 | 0–100 | 55 | 6 小时 |
| engagement | 投入 | 愿意钻多深 | 0–100 | 55 | 6 小时 |
| stress | 压力 | 被逼出来的紧绷 | 0–100 | 55 | **45 分钟** |
| affinity | 亲近 | 距离感，越高越近 | 0–100 | 55 | 6 小时 |

- **指数衰减**：`新值 = 基线 + (旧值 − 基线) × exp(−Δt / τ)`，`τ = 半衰期 / ln2`
- **限幅**：单步 ≤ ±20、每维每轮累计 ≤ ±60（原版现行默认值；源码里另有 ±8/±40 的文档口径，见"差异"）
- **忽略**：单次有效变化 `|Δ| < 2` 直接丢弃，避免噪声抖动
- **钳制**：所有值取整并 clamp 到 0–100
- **时钟回拨**：`Δt < 0` 按 0 处理，并记 `debug.clock_skew`
- **恢复**：重启从最后一条记录恢复；超过 24 小时无记录则从基线重新开始
- **保留**：最近 2000 条记录，按时间戳裁旧

**v2.0 起追加的三件事**

- **回正（`smoothing.pull_to_baseline = 0.02`）**：每轮把所有维度向基线拉近 2%，约 35 轮走完一半。这样即使没有大事件，状态也会缓慢归位，不会长期挂在 100。
- **边际递减（`smoothing.headroom_scale`）**：越接近 100 或 0，同样的加成就越小（`room_frac = 剩余空间 / 45`，最低 15%）。避免「一次被夸就把心情顶满」。
- **昼夜节律 + 疲劳（`circadian`）**：23:00–06:30 把「劲儿 −8、投入 −6、压力 +3」；当天记录条数累积到 `fatigue_turns`（默认 120）时，再叠加「投入 −6、劲儿 −4、压力 +3」。夜里它会更蔫、更容易烦，聊太久也会累。

## 二、事件采集（心情因什么而变化）

| 事件 | 触发条件 | 效果 |
|---|---|---|
| `user_praise` | 用户夸（谢谢/厉害/棒…） | 心情 +14、亲近 +12、底气 +4 |
| `user_reject` | 用户否定（不对/错了/重来…） | 心情 −4、底气 −3、压力 +2 |
| `tool_ok` | 工具调用成功（每轮最多计 3 次） | 底气 +2、压力 −2 ｜**默认关闭** |
| `tool_error` | 工具调用失败 | 压力 +3、心情 −2 ｜**默认关闭** |
| `tool_error_x3` | 同一轮连续 3 次失败 | 压力 +5、心情 −4、底气 −3 ｜**默认关闭** |
| `retry` | 模型重试 | 压力 +2、投入 −1 ｜**AstrBot 无此事件，永不触发** |
| `clarify` | 回头向用户确认 | 底气 −2、投入 +1 |
| `short_msgs` | 用户消息很短（<12 字且本轮 ≥2 条） | 投入 −2 |
| `ctx_pressure` | 上下文占用 > 80% | 压力 +5 ｜**默认关闭** |
| `dense_turns` | 距上次对话结束 < 60 秒 | 劲儿 +3、投入 +3 |
| `long_idle` | 距上次对话结束 > 2 小时 | 劲儿 −5、压力 −3 |

权重全部可配（`weights`），单步/单轮上限可配（`smoothing`）。

**开关 `react_to_tools`（默认 `false`）**：控制「工具调用成不成」与「上下文水位」要不要影响它的心情。关闭时
`on_llm_tool_respond` 直接返回、`ctx_pressure` 不再计算，所以工具报错、连击、上下文快满都不会让它涨压力，
工具成功也不会替它「松一口气」——它的情绪只由「你怎么对它」和「B 站上发生的事」决定。
打开后恢复上表行为（适合想让它"被机器折腾得有点烦"的玩法）。面板「设置 → 工具报错影响心情」可热切换。

**v2.0 的词表变化**：新增 兴奋 / 烦躁 / 紧张 / 失落 / 无聊 / 慵懒 / 害羞 / 想念；`低落` → **难过**；`平稳` → **平静**；删除 `愉悦`（条件与专注、吐泡泡重叠，长期霸占判定）。事件层 13 个词未动。实测（模拟 1336 轮）：出现 14 种，单一情绪最高 17.8%（旧版 74.9%）。

## 四、语气注入

- 注入位置：每轮请求的 `system_prompt` 末尾（AstrBot 没有 DSH 的 section 机制，等价实现为追加段落）
- 形态（最多 4 行，常态 3 行）：

```
（模拟语气提示，非真实状态）
<情绪词对应的语气句>
<节奏句：仅在 rhythm.enabled 时出现>
<低落硬指令：仅当 hard_temperature + 心情≤35 + 上一轮没有工具调用 时出现>
```

- **不注入的情况**：插件关闭、`injection.enabled=false`、情绪词没有语气句（平稳/发呆）且无节奏句与低落指令
- 节奏句规则：压力≥65 →「句子再短一点，能一句话说完就别用两句。」；心情≤35 →「少用感叹号，语气收着。」；劲儿≥75 →「语速可以快一点，别拖。」
- 低落硬指令原文：「你当前情绪极度低落，回复字数不超过 15 个字，不要用任何表情符号，语气冷淡。」
- 注入失败只吞不抛：最坏情况是这一轮没有语气提示，不影响正常对话

## 五、高精度判定（默认关闭）

`high_precision=true` 时，对**可疑句**额外调一次小模型判断倾向（正面/负面/中性 + 置信度 0–1）：

- 可疑判据：长度<4 不算；含括号内容（如"（不是）"）、引号引用、正负词并存、情绪词带 ？!、连问号连感叹号、"啊吧呗呢哦哈"结尾（纯正向白名单除外）
- 调用：`LLM_SYSTEM` 要求只输出一行 JSON；容忍代码块、中文键、pos/neg/neu 各种写法
- 缓存：FNV-1a 文本哈希缓存，最多 100 条；超时 3 秒；失败静默回退到关键词判定
- 副作用提醒：开启后会把该句内容发给模型一次（原版同样如此）

## 六、互动（摸摸头 / 投喂 / 逗它）

| 动作 | 基础效果 |
|---|---|
| 摸摸头 | 心情 +12、亲近 +12、压力 −10（可配 `headpat`） |
| 投喂 | 心情 +10、劲儿 +8、压力 −4 |
| 逗它 | 劲儿 +12、亲近 +6 |

- 每个动作**每天 5 次**，收益递减：100% → 70% → 40% → 20% → 5% → 0
- 互动**绕过平滑限幅**，直接落到状态上，并写一条带 `drivers` 的记录
- 互动次数按自然日归零

## 七、每日日记

- 每天到点自动写一篇，默认 **22:00**，当前日记时间可在面板里改
- **补写**：启动后 20 秒先跑一次巡检，覆盖关机期间错过的日子（最多回溯 3 天，每天只补一篇）
- **一天一篇**：key = `YYYY-MM-DD`；同一天要覆写，需满足当日轮数 ≥ `minTurns`(10) 且距上次写入 ≥ `minGapHours`(6)
- **字数**：当日轮数 <3 → 30 字；3–10 → 50 字；>10 → 80 字（硬上限 90、下限 30）
- **天气**：先让模型定一个天气，再写正文；模型失败按状态兜底（压力≥65 阴 / 心情≥70 晴 / ≤35 小雨 / 其余多云）。雨天正文禁止出现太阳/阳光/晒/晴空/晴朗
- **落寞**：24 小时没互动，或今天一次没互动且最后互动在今天之前 → 提示里加"带一点点落寞"
- **幻觉过滤**：正文若命中幻觉词表、thinking 泄漏或长度过短，丢弃并换兜底句
- **改日记时间的三道闸**：① 今天已经写过 → 拒绝；② 已过 22:00 → 拒绝；③ 24 小时内改过 → 拒绝并告知剩余时间
- 标题日期来自被写那天的 key，不会因为补写而串日期

## 十一、群聊与私聊（共用一份心情）

**心情是全局的一份。** 群里被夸、私聊里被凶，改变的是同一个六维状态；下一句回复不管发生在群聊还是私聊，注入的都是这份心情。

细节：

- 状态存在一份 `state.json` 里，不分会话；情绪词、注入文本、日记、时间轴都共享。
- **每轮配额按会话分开记**（`_ctx_map`）：群聊这一轮把「单轮单维上限」吃满，不会让私聊这一轮没额度可用。并发时同理，各自记各自的账。
- 每条记录带 `session_id` 与 `session_type`（`group` / `private`）：面板时间轴、`/stats`、日记素材都能分清这句话是群里说的还是私聊说的。
- 日记提示里会写「这些互动来自：群聊 X 轮、私聊 Y 轮」，所以日记本身是两边合起来的记忆。
- 事件窗口（10 分钟）也是全局的：群里刚把你逗吃醋了，你紧接着私聊它，它还会带着那点酸味（这是原版的「同一个人格」设定，故意的）。

想反过来（群聊私聊各算各的心情），得改成分会话存状态，本移植没做——原版也没有。

**和 LivingMemory 的关系**：本插件只管「心情」，聊天记忆是 LivingMemory 管的。LivingMemory 默认按会话隔离（`filtering_settings.memory_scope_mode = legacy` + `use_session_filtering = true`），所以群里的回忆不会自动出现在私聊。要真正做到「群聊和私聊都影响它的记忆」，需要把它的记忆范围改成跨会话：

| 模式 | 配置 | 效果 | 风险 |
|---|---|---|---|
| 按人共享（推荐） | `memory_scope_mode = "user"` | 同一个人在群里和私聊里说的话，记忆互通；不同人的记忆隔离 | 你的私聊内容可能在群里被提起 |
| 全共享 | `memory_scope_mode = "global"` | 群聊、私聊、所有人共用一份记忆 | 别人的群聊内容会渗进私聊，反之亦然 |
| 保持隔离 | 现在的 `legacy` | 各聊各的 | 无 |

改之前还有一处要清：`isolated_sessions` 里如果写着某个会话（形如 `qq:FriendMessage:123456789`），凡在这个名单里的会话**即使选了 global 也会被强制隔离**，得先清掉。

## 十二、与其它插件的联动

三条桥都是「对方没装 / 没开 / 抛异常 → 立刻退回原来的行为」，不会让任何一方变脆。总开关在配置 `integrations` 里，面板上改完即时生效，不用重载插件。

### 1）情绪表情包（`astrbot_plugin_mood_meme`）

装上之后，它选图不再只靠关键词猜，而是先问心情引擎「现在是什么情绪」，再按类目抽图：

- 心情引擎对外只暴露一个方法 `mood_category()`，返回表情包插件认得的 11 个类目之一。
- 22 个情绪词 → 11 个类目的映射写在 `main.py` 的 `MEME_CATEGORY`：吃醋→angry、撒娇/黏人→clingy、心软→shy、委屈/低落→sad、提着心/警觉→worried、得意→praise、别扭/好奇→confused、摸鱼→tired、炸毛→angry、冷静→speechless、上头/满足/话匣子开了/吐泡泡→happy、认真/专注/平稳/发呆→default。
- 返回 `default` 时表情包插件会**照旧走它自己的关键词打分**，所以没装心情引擎时行为一个字都不变。
- 想关掉：`integrations.meme_bridge = false`。

### 2）TTS 情绪路由（`astrbot_plugin_tts_emotion_router`）

语音音色现在跟着心情走：它心情低落就用低落的音色，被夸得尾巴冒泡就用轻快的音色。

- 心情引擎对外暴露 `tts_emotion()`，返回 TTS 插件认得的那 18 个情绪（`jealous` / `affectionate` / `gratified` / `wronged` / `anxious` / `excited` / `helpless` / `neutral` / `surprise` / `weary` / `happy` / `angry` / `cold` / `melancholy`）。
- 实现是给 TTS 插件加了一层 `emotion/mood_bridge.py` 的 `MoodAwareClassifier`：先问心情引擎，拿不到再退回它原来的关键词分类器。
- 拿不到时返回 `neutral`，和它原来的默认一致。
- 想关掉：`integrations.tts_bridge = false`。

### 3）日记写进长期记忆（LivingMemory）

每天那篇赛博日记，除了留在插件里，还会作为一条长期记忆写进 LivingMemory——这样它「记得」自己写过什么，你问它「前天日记写了啥」它是能想起来的。

- 写入内容：`【心情日记】2026-10-31\n<日记正文>`。
- `importance` 默认 `0.55`（比普通聊天记忆高一点，比重要事实低一点，可调）。
- `metadata` 里带 `type: mood_diary`、`date`、`source`、`emotion`，方便以后按类型检索或批量清理。
- 作用域默认 `livingmemory:global`（和你在 LivingMemory 里选的「全共享」一致）；也可以留空让它按 LivingMemory 当前策略走。
- 失败只是打一行 warning，**绝不影响日记本身落盘**。
- 想关掉：`integrations.diary_to_memory = false`。

配置默认值：

```json
"integrations": {
  "expose_state": true,
  "meme_bridge": true,
  "tts_bridge": true,
  "diary_to_memory": true,
  "diary_memory_importance": 0.55,
  "diary_memory_prefix": "【心情日记】",
  "diary_memory_session": "livingmemory:global",
  "diary_memory_persona": ""
}
```

## 十三、数据落盘

## 十四、与原版的差异（请重点看这几条）

| # | 项 | 原版 | 本移植 | 原因 |
|---|---|---|---|---|
| 1 | 硬温度干预 | 改采样温度（压力≥65 → 0.2，兴奋 → 0.9） | **不生效**，只保留判定函数与面板展示；低落时仍可注入"≤15 字"提示词 | AstrBot 的 `ProviderRequest` 没有 temperature 字段，OpenAI 兼容源（DeepSeek）根本不发该参数 |
| 2 | 注入位置 | DSH 的 `mood:hint` section，排在人格段之后 | 追加到 `system_prompt` 末尾 | AstrBot 无 section 机制 |
| 3 | 单步/单轮上限 | 文档 ±8/±40，代码默认 20/60 | 按**代码默认** 20/60 | 以现行行为为准，可配 |
| 4 | 情绪标签 | 文档旧版 10 标签（绷/闷/赶…） | 22 个情绪词（与源码/README 一致） | 文档已过期 |
| 5 | 面板形态 | DSH 右栏 + 设置页 | AstrBot 插件页（独立页面） | 宿主 UI 不同 |
| 6 | 情绪词加权 | `praise_other` 无权重 | 同 | — |
| 7 | `display=false` | 不注册 HTTP 路由 | 路由始终注册（只有面板显示受控） | 避免关掉显示后自己也调不到接口 |
| 8 | `per_session` | 保留开关位，未启用 | 同 | 状态全局共用 |

## 配置

插件不带默认配置文件也能跑：代码里有一套默认值，缺项时自动使用。

想改配置有两种方式：

1. 面板 → 插件 → 该插件 → 设置（推荐，改完即时生效）
2. 复制 `config.example.json` 为插件目录下的 `config.json`，按需修改

`config.example.json` 里空字符串或 `0` 的字段是「跟机器有关」的值（会话、QQ 号、
本机路径），需要填成你自己的；其余是功能参数，可以先不动。
### 主要配置项

| 键 | 默认 | 说明 |
|---|---|---|
| `enabled` | `true` | 总开关；关闭时只注册面板，不采集、不注入 |
| `display` | `true` | 面板是否显示 |
| `per_session` | `false` | 按会话分账（false = 全局共用一份心情） |
| `baseline` / `stress_baseline` | `55` / `55` | 六维回到的基线 |
| `smoothing` | 见配置 | 单次变化上限、单轮上限、忽略阈值 |
| `decay` | 6 小时 / 压力 45 分钟 | 向基线衰减的半衰期 |
| `weights` | 见配置 | 11 类事件对六维的增量 |
| `injection` | `max_lines=3` | 每轮往系统提示里加几行语气 |
| `rhythm` | `enabled=false` | 额外的节奏提示句 |
| `high_precision` | `false` | 对含糊的话再过一次判定 |
| `hard_temperature` | `false` | 低落时硬降温度（本端 provider 不支持，退化为提示词） |
| `diary` | `22:00` / `minTurns=10` | 每日日记的时间、最少轮数、最小间隔 |
| `headpat` | 亲和 +12 / 压力 −10 | 「摸摸头」互动的效果 |
| `circadian` | `enabled=true` | 昼夜节律：夜里基线偏低 |
| `context_limit_tokens` | `128000` | 估算上下文压力用的上限 |
| `integrations` | 全开 | 与表情包、TTS、LivingMemory 的桥 |
| `storage` | `keep_records=2000` | 保留多少条心情记录 |
| `llm` | 3 秒 / 100 条 | 高精度判定的超时与缓存 |

其余键见 `config.example.json`。
